# Asynchronous JavaScript & RESTful APIs – Weather Dashboard

## Features
- Uses Fetch API and async/await.
- Gets city coordinates from Open-Meteo geocoding API.
- Fetches live temperature, humidity, apparent temperature and wind speed.
- Handles network errors and unknown cities.
- Dynamically renders JSON data.

## Run
Open `index.html` in a browser. No API key or npm install is required.
