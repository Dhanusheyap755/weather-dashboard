## 📌 Project Overview
A responsive weather analytics web application that demonstrates real-time asynchronous API consumption with **JavaScript Fetch API and async/await**. Users can query global cities to retrieve live meteorological data, ambient temperatures, humidity levels, and meteorological condition icons.

---

## 🚀 Key Features
- **Asynchronous Data Pipeline:** Non-blocking REST API calls using `async/await` and Promises.
- **Dynamic City Search:** Instantly geolocates coordinates and fetches corresponding temperature, wind speed, and atmospheric pressure.
- **Responsive Interface:** Modern glassmorphism card layouts displaying current weather conditions.
